# Portafolio Web - José Ramírez Guaigua

Este es el repositorio para el sitio web estático del artista contemporáneo José Ramírez Guaigua, optimizado para **GitHub Pages**.

## 🚀 Cómo alojar en GitHub Pages

1. **Crear un repositorio en GitHub:**
   - Ve a [GitHub](https://github.com) y crea un nuevo repositorio llamado `joseramirezguaigua.github.io` (o el nombre que prefieras).

2. **Subir los archivos:**
   - Descomprime el paquete zip e sube los archivos (`index.html`, `README.md`, etc.) a la rama principal (`main`).

3. **Activar GitHub Pages:**
   - Ve a **Settings** > **Pages** en tu repositorio de GitHub.
   - En **Source**, selecciona `Deploy from a branch`.
   - Selecciona la rama `main` y la carpeta `/ (root)`.
   - Haz clic en **Save**.

4. **Dominio Personalizado (Opcional - para joseramirezguaigua.com):**
   - En la sección **Custom domain** ingresa `joseramirezguaigua.com`.
   - Asegúrate de configurar tus registros DNS (CNAME / A records) en tu proveedor de dominio apuntando a GitHub Pages.
